### 🦘 [WildLens](https://github.com/mingjun6886/wildlens)
Serverless wildlife image tagging on AWS: MegaDetector → SpeciesNet in a container Lambda, fed by S3 → SQS (+ DLQ), behind a Cognito-protected API.

- 💸 Reserved concurrency + DLQ cap a worst-case runaway at ~$4 instead of ~$80
- 🏗️ 100% Terraform; CI uses OIDC, no long-lived secrets
- 🔭 JSON logs, X-Ray, CloudWatch dashboard and alarms

### 🔥 [FIREBREAK](https://github.com/mingjun6886/FIT5120-Assignment-TP03)
Team project (Monash FIT5120): a household bushfire-preparedness web app. Households build and save an evacuation plan, see local fire danger and historical fire context on a map, check road disruptions near their destinations, and run a meet-up simulation against their plan.

- 🧩 Vue 3 + Vite frontend, FastAPI + Pydantic services, MySQL (with spatial open data), Docker
- 🛡️ Rule-based guidance; the safety Q&A model returns only IDs of reviewed answers, so it can't invent advice
- 🙋 My role: **frontend, UI/UX, backend, voice control** and other features, in a team of five
- 🗣️ Voice control: hands-free navigation and read-outs of weather, fire danger and plan status, with an AI-selected action from a closed list so it can only navigate or read, never change data
- 🗂️ Delivered over three frozen iterations

**[View the repo →](https://github.com/mingjun6886/FIT5120-Assignment-TP03)**
